A calm course rhythm

Read, notice, apply, check and keep useful evidence

Each section is a complete learning package in the same structural rhythm as the Year 10 sister course.

1. Read

Learn one named concept from the authorised course sequence.

2. Notice

Use purposeful visuals and a complete video or non-video pathway.

3. Apply

Rehearse the concept in a linked Applied Learning Activity.

4. Check and keep

Use feedback, write the capstone and select folio evidence.
